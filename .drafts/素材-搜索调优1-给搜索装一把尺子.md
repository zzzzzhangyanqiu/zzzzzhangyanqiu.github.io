## 第 1 篇：核心张力（一句话钩子）

**第一次跑评测，新版反而退步（0.840 → 0.806），数据当场拦下一个我以为没问题、本来要上线的版本。**

灵魂：三个痛点里「没抓手」是总钥匙——因为没尺子，越凭感觉调越糟；先修路（调试通道 + 评测），再让每个改动用数据说话。

写法建议：**不要平铺"我做了 ABC"，而是用"初版 -0.034 退步"这一个事件，把词单怎么选、怎么判分、怎么读数全串进去。** 细节长在叙事里，不堆 bullet。

## 大纲（叙事骨架）

**0. 开篇 · 一个说不清的 badcase**
- 切入：千星 / 12.8 万下载 / 621 fork 的 `cannbot-skills`，被一个 61 星、描述短的 `GLM-skills` 压在后面。凭直觉根本说不清谁对——这就是"没有尺子"的日常焦虑。
- 把读者带到痛点：搜索调优最大的问题不是"不会调"，是"调完不知道是好是坏"。

**1. 三个痛点，真正卡住的是第三个**
- 召回过松（多词任一命中即召回，高质量沉底）。
- 打分不可维护（几百字符 painless 单行脚本塞 Nacos，无版本、无 review、改一次触发 ES 重编译）。
- **没抓手（总钥匙）**：ES 只能 Kibana 摸，工具/AI 取不到证；改动好坏全靠主观感觉。
- 点题：先修路（调试通道 + 评测体系），再调优。

**2. 修路之一 · 把 ES 变成能取证的**
- `EsDebugController`，`@Profile` 限定、pro 不注册天然 404，凭据留服务端。
- 关键能力：抓"真实下发的 DSL"——调优闭环从"天"级（人肉 Kibana）缩到"秒"级（抓 DSL → 改写重放 → 看结果）。
- 这里点到为止，不展开 DSL 细节（留给后两篇）。

**3. 修路之二 · 给搜索装一把尺子（评测体系，本篇重头）**
- 要解决三个"怎么才不骗自己"：
  - **词单怎么选**：用线上热搜 top30 真实词，不是自己拍脑袋造语义词。（这条后面用反面教训坐实）
  - **怎么判分才不作弊**：0~4 分**盲判**——两个版本结果并集打乱、不带来源；判分落盘、同一(词,文档)**永不重判**、跨会话一致，缓存累积 456 条 → 回归零标注成本、分钟级出数。
  - **A/B 怎么定义才公平**：A = 冻结的"改造前打分基线"（2026-06-10 线上捕获）重放，B = 当前真实链路，**同一时刻、同一语料、逐位对比**。
- 一句话讲清 NDCG@10 的直觉（理想排序得满分，好结果排越后扣越多），不堆公式。

**4. 高潮 · 尺子第一次就拦住了我**
- 第一次全词单评测：新版 0.840 → **0.806，整体退步 -0.034**。
- 复盘：mirrors（镜像仓）压太狠（0.55），导航词上"正主镜像被野生克隆反超"；而真实热搜恰恰以导航词为主——**初版偏偏只用 2 个语义词校准，样本不代表真实流量**。
- 收束：评测拦住了一个会带病上线的版本。这就是"修路"的回报。

**5. 怎么读数才不骗自己（方法论，本篇第二个硬核）**
- **基线 A 会漂移**：语料更新、判分新增、判分校正都会让 A 的绝对值动（0.840 → 0.850）。所以**只比同一时刻的 A/B 差值，绝对值跨天比较没有意义**。
- **判分本身也会错**：`图像分类` 一度显示 -0.099"退步"，根因是把一个 0 星 / 11 下载 / 无活跃的死仓（精确命名）误判成 4 分；订正 4→3 后收窄到 -0.052（落进噪声带）。→ 教训：精确命名命中 ≠ 高判分，死仓要按活跃/信号降级。
- **副本噪声**：ES 副本间 IDF 漂移，单词 NDCG 自带 ±0.02~0.05 抖动，**小于 0.05 的单词差异不是信号，看词单均值**。

**6. 收口 · 成绩与价值观**
- 成绩用演进时间线讲（见下方数字），强调"一来一回"才是真实幅度：首评 -0.034 → 最终 +0.07 量级。
- 价值观收尾：搜索调优真正的资产不是某个参数，是那把让你凭数据、而不是凭感觉的尺子。后面两篇（打分 / 召回）的每个决策，都是这把尺子量出来的。

## 接地气素材包（按「约束 / 数字 / 怕」三类）

### A. 真实的约束（凭什么信这个评测）
- 词单 = 线上热搜 top30，代表真实流量；反面教训：初版用 2 个语义词校准 → 真实热搜以**导航词**为主 → 差点上线整体退步版本。"样本要代表真实流量"是用血换的。
- 盲判：并集打乱、不带来源、永不重判、缓存 456 条、跨会话一致。
- A/B 同时刻同语料逐位，A 是"冻结的改造前函数重放"。

### B. 真实的数字（算给你看 / 拦得住人）
- 初版整体退步：0.840 → 0.806（-0.034）。
- 判分误判致假退步：图像分类 -0.099 → 订正 4→3 后 -0.052。
- 副本噪声 ±0.02~0.05，阈值 0.05。
- 演进时间线（剔零结果口径，只比同时刻 A/B）：
  | 节点 | A | B | Δ |
  |---|---|---|---|
  | 06-11 首评（初版） | 0.840 | 0.806 | **-0.034**（拦住带病版本）|
  | 三轮校准 | 0.841 | 0.847 | +0.006 |
  | import-cap 1.5 | 0.848 | 0.896 | +0.048 |
  | download/fork 因子 | 0.841 | 0.894 | +0.052 |
  | history 字段修复复测 | 0.850 | 0.908 | +0.058 |
  | 活跃度时间衰减上线 | 0.853 | **0.924** | **+0.072（迄今最高）**|

### C. 上线前的怕（怎么防翻车——本篇略带，详见第 2 篇）
- 调试接口 @Profile 限定，pro 天然 404，凭据不外泄（安全设计）。
- 评测体系本身就是最大的"防翻车"——上线前先重放，错的进不去。
