> 设想：现有40亿个整数，如果判断给定的整数是否存在这40亿个整数中？

## 思路 ##

### 使用HashMap ###

首先，我们思考比较简单的方式，使用`hashmap`来存储，对整数进行`hash`计算，取出时只需要进行`hashmap.containsKey()`进行校验即可。


我们都知道，`hashmap`存入数据时，会将`key`值进行`hash()`，然后存入数组中，如果40亿个整数重复度较高，那么使用此方式也许可行，我们可以想到，由于`hashmap`要对`key`进行`hash()`计算，所以效率会偏低。并且如果我们的40亿个整数重复度特别低，不考虑是否能容纳下的问题，就算是可以容纳的下，`hashmap.containsKey()`效率也会特别低。其实我们并不需要`hashmap`中的`value`属性，那么`set`集合是不是比`map`更为合适呢？

### HashSet ###

上面我们分析了`hashmap`的可行性，考虑到不需要`value`，我们改用`hashset`方式来存储40亿个整数。我们都知道，在`java`中，`int`内存占用为4个字节，那么此方式的总空间占用为：40亿 x 4字节 = 160亿个字节 ，转换为GB后约等于14.9G，很明显，14.9G的空间，对我们来说有些不太符合实际，而且此方式也存在和`hashmap`同样的问题，如果在15G的数据中查找，耗费的时间也不是我们可以接收的。

### 还有别的方法么？ ###

转换一下思路，现在我们开始思考，`java`中一个`int`类型的变量占用4字节也就是32位，`long`类型的变量占用64位，我们都知道二进制位中以1，0来表示当前位数，那我们是否可以这样思考，使用二进制来存储40亿个整数呢？1就代表存在，0代表不存在。比如初始化一个`long`变量，拿整数43来举例，我们就把变量中的第43位改为1，存储完毕后只需要判断对应位上的数值是0还是1就可以了，到了这里，有的同学可能会有疑惑：你这一个数只能存64个位啊，那剩下的怎么办？  先别急，此处我们先留下一个悬念，稍后我们拿Java中的一种集合来详细分析此方法。

### BitSet集合 ###

> 针对上面的问题，Java中早已经为我们提供了对应的工具类：BitSet。

#### 具体使用 ####


```java
//初始化
BitSet bs = new BitSet();
//赋值
bs.set(2);
bs.set(4);
bs.set(9);
//取值
System.out.println(bs.get(2));
System.out.println(bs.get(3));
```


​	

以上代码运行结果为：

```java
true
false
```

#### 源码分析 ####

首先，我们看此类的注释，发现了其中两句

```java
<p>By default, all bits in the set initially have the value
{@code false}.
BitSet is not safe for multithreaded use without
 external synchronization.
```

通过这两句我们可以得知：1：所有的位都有一个默认的value值{false}，2：BitSet不是线程安全的。所以在多线程使用中要考虑线程同步问题。

- 初始化

分析初始化，可以看到该方法中有一个重载：

```java
private final static int ADDRESS_BITS_PER_WORD = 6;

private final static int BITS_PER_WORD = 1 << ADDRESS_BITS_PER_WORD;

public BitSet() {
    initWords(BITS_PER_WORD);
    sizeIsSticky = false;
}

public BitSet(int nbits) {
    if (nbits < 0)
        throw new NegativeArraySizeException("nbits < 0: " + nbits);

    initWords(nbits);
    sizeIsSticky = true;
}
```

如果初始化时我们不指定大小，默认会为我们传入1 << 6 = 64个位大小，然后调用`initWords(nbits)`
	
```java
private void initWords(int nbits) {
    words = new long[wordIndex(nbits-1) + 1];
}

/**
 * Given a bit index, return word index containing it.
 */
private static int wordIndex(int bitIndex) {
    return bitIndex >> ADDRESS_BITS_PER_WORD;
}
```





可以看到，`BitSet`底层就是一个`long`类型的数组，注意此处的`wordIndex`方法，这个方法是整个`BitSet`的核心逻辑，此方法的注释：给定一个位索引，返回在数组中的索引，还记得我们上面留下的悬念么：一个数只能存64个位，那剩下的怎么办？ 因为一个`long`类型数组可以存储多个`long`类型的变量，每个`long`类型的变量还拥有64个位，这样`BitSet`就可以存储多个位了，用一个图来表示就是

![](/images/oss/18-12-29/49825353.jpg)


每个`Long`类型变量都是一个位区间，而区间的大小就是`Long`类型的位数：64，而BitSet的初始化大小为`1 << 6 >> 6`，也就是`BitSet`的默认初始化大小为一个区间。

- put

下面我们来看`put()`的代码，`put()`方法也有一个重载：

```java
public void set(int bitIndex) {
    if (bitIndex < 0)
        throw new IndexOutOfBoundsException("bitIndex < 0: " + bitIndex);

    int wordIndex = wordIndex(bitIndex);		
    expandTo(wordIndex);						

    words[wordIndex] |= (1L << bitIndex); 		

    checkInvariants();
}

public void set(int bitIndex, boolean value) {
    if (value)
        set(bitIndex);
    else
        clear(bitIndex);
}
```




首先，调用`wordIndex(bitIndex)`方法计算出传入的位数在Long数组中的索引位置，然后调用`expandTo(wordIndex)`方法来确定是否需要扩大数组，expandTo方法的代码为：

```java
private void expandTo(int wordIndex) {
    int wordsRequired = wordIndex+1;
    if (wordsInUse < wordsRequired) {
        ensureCapacity(wordsRequired);
        wordsInUse = wordsRequired;
    }
}
```

然后用取出`words[wordIndex]`，用对应区间的数据和`1L << bitIndex`做或运算，把对应位上的数据设置为1。这里可能有的同学会问了，如果我传入的参数是90，根据计算应该在第二个区间，但是第二个区间只有64个位，90应该怎么找到对应的位呢？这里，就设计到了位的溢出问题。简单来讲，位的溢出就是如果你在64位上左移90位，计算机会使用90对64进行取模操作，然后将得到的结果位设置为1。90 % 64 = 26，也就是说，90最终的位置是数组中的第二个区间的26位。

- get

```java
	public boolean get(int bitIndex) {
        if (bitIndex < 0)
            throw new IndexOutOfBoundsException("bitIndex < 0: " + bitIndex);

        checkInvariants();

        int wordIndex = wordIndex(bitIndex);
        return (wordIndex < wordsInUse)
            && ((words[wordIndex] & (1L << bitIndex)) != 0);
    }
```

了解put之后，get操作就很简单了，`wordIndex(bitIndex)`计算出位数所属的区间，使用此区间和`1L << bitIndex`做与运算，如果存在，那么结果必定会有一位是1，所以使用结果是否等于0来判断此数据是否存在。

#### 其它应用 ####

了解此思想之后，就可以应用到其它方面，如给定两个数组a:{1,6,6,8,9,2,7,10,52},b:{2,5,6,15,63,24}如何判断b中的哪些元素在a中出现过？

上面我们提到使用二进制位来区分数是否存在，那么我们是否可以创建两个long类型的变量，第一个标识a数组的各个变量是否存在，第二个则标识b数组的各个变量是否存在，最后两个数变量进行与运算，只要为1的位就是两个数组相同的变量呢？话不多说，直接上代码：

```java
	int [] a = new int[]{1,6,6,8,9,2,7,10,52};
    int [] b = new int[]{2,5,6,15,63,24};
    long signA = 0L;
    long signB = 0L;
    for (int i = 0; i < a.length; i++){
        signA |= 1L << a[i];
    }
    for (int i = 0; i < b.length; i++){
        signB |= 1L << b[i];
    }
    signA &= signB;
    System.out.println(Long.toBinaryString(signA));
```

以上代码输出结果为

```java
	1000100
```

从右至左，可以看到，第三位和第七位的位数为1，对应的数据就是2，6。
