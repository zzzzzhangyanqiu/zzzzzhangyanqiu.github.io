## 组合模式

> 组合模式是分区设计模式。组合模式描述了一组对象，其处理方式与相同类型对象的单个实例相同。组合模式的意图是将对象“组合”成树结构以表示部分整体层次结构。通过实现组合模式，客户端可以统一处理单个对象和组合。

### 问题的产生

根据如上结构，我们开始编写代码，首先创建文件夹类

```java

/**
     * 名称
     */
private String fileName;

/**
     * 该文件夹下的文件夹
     */
private List<Folder> folders;

/**
     * 该文件夹下的PNG文件
     */
private List<PngFile> pngFiles;

/**
     * 该文件夹下的TXT文件
     */
private List<TxtFile> txtFiles;

public Folder(String fileName) {
    this.fileName = fileName;
    folders = new ArrayList<>();
    pngFiles = new ArrayList<>();
    txtFiles = new ArrayList<>();
}

/**
     * 打开文件
     */
public void open() {
    System.out.println("打开文件夹：" + fileName);

    for (Folder folder : folders) {
        folder.open();
    }

    for (PngFile pngFile : pngFiles) {
        pngFile.open();
    }

    for (TxtFile txtFile : txtFiles) {
        txtFile.open();
    }
    System.out.println("--------------------------------------------");
}

/**
     * 添加文件夹
     *
     * @param folder
     */
public void addFolder(Folder folder) {
    folders.add(folder);
}

/**
     * 添加图片文件
     *
     * @param pngFile
     */
public void addPng(PngFile pngFile) {
    pngFiles.add(pngFile);
}

/**
     * 添加TXT文件夹
     *
     * @param txtFile
     */
public void addFolder(TxtFile txtFile) {
    txtFiles.add(txtFile);
}
```

然后创建图片文件类

到目前为止，我们已经实现了一个超简易的文件系统。回顾一下上面的代码，可以发现很多问题，如果我们以后要再加一种文件类型，就要向`Folder`类增加一个集合来存储，并且同时修改`open()`方法，这违背了`对拓展开放，对修改关闭`的原则。其次，如果以后的文件类型比较多，`Folder`类的代码会变的越来越多，时间长了也不利于维护。了解了这些问题之后，我们一起来看组合模式。

### 组合模式介绍

首先来看组合模式的`UML`类图

![](https://suiyueranzly.oss-cn-beijing.aliyuncs.com/%E5%8D%9A%E5%AE%A2/%E7%BB%84%E5%90%88%E6%A8%A1%E5%BC%8F/%E7%BB%84%E5%90%88%E6%A8%A1%E5%BC%8FUML%E5%9B%BE.png)

整个组合模式分为四个角色

`Component`：抽象接口，也可以理解为整个模式中统一对外暴露的接口。

`Leaf`：叶子节点，即没有子节点的节点，如上面例子中的文件。

`Composite`：组合节点，即下面还有子节点的节点，如上面例子中的文件夹。

`Client`：客户端，即调用方。

现在我们来用组合模式改写上面代码

首先，创建抽象类，也就是`Component`对象

```java
public abstract class File {

    /**
     * 文件名
     */
    protected String fileName;

    /**
     * 打开文件
     */
    protected abstract void open();

    /**
     * 添加文件
     */
    protected abstract void add(File file);

}
```

其次，创建文件夹类，对应`Composite`角色

```java
public class Folder extends File {

    private List<File> childrent;

    public Folder(String fileName) {
        childrent = new ArrayList<>();
        super.fileName = fileName;
    }

    /**
     * 打开文件
     */
    @Override
    public void open() {
        System.out.println("打开文件夹：" + fileName);

        //调用子文件的open()方法
        for (File file : childrent) {
            file.open();
        }
        System.out.println("--------------------------------------------");
    }

    /**
     * 添加文件
     *
     * @param file
     */
    @Override
    public void add(File file) {
        childrent.add(file);
    }
}
```

最后创建我们的文件类，对应`Leaf`角色

```java
public class PngFile extends File {

    public PngFile(String fileName) {
        super.fileName = fileName;
    }
    /**
     * 打开文件
     */
    @Override
    public void open() {
        System.out.println("调用图片查看器打开文件：" + fileName);
    }

    /**
     * 添加文件
     *
     * @param file
     */
    @Override
    public void add(File file) {
        //文件不能再添加子文件了，这里抛出异常
        throw new UnsupportedOperationException("文件不能添加子文件!");
    }
}
```

```java
public class TxtFile extends File {

    public TxtFile(String fileName) {
        super.fileName = fileName;
    }
    /**
     * 打开文件
     */
    @Override
    public void open() {
        System.out.println("调用文本编辑器打开文件：" + fileName);
    }

    /**
     * 添加文件
     *
     * @param file
     */
    @Override
    public void add(File file) {
        //文件不能再添加子文件了，抛出异常
        throw new UnsupportedOperationException("文件不能添加子文件!");
    }
}
```

最后编写测试代码，也就是`Client`

```java
//模拟测试数据
File top, folder, folder1, txt, txt1, png, png1;
folder = new Folder("文件夹");
folder1 = new Folder("文件夹1");
txt = new TxtFile("文件夹中的txt文件");

png = new PngFile(("文件夹中的png文件"));
png1 = new PngFile(("文件夹1中的png文件1"));
top = new Folder("顶层文件夹");
folder.add(txt);
folder.add(png);
folder1.add(txt1);
folder1.add(png1);
top.add(folder);
top.add(folder1);


//调用打开方法
top.open();
```

```java

打开文件夹：文件夹
调用文本编辑器打开文件：文件夹中的txt文件
调用图片查看器打开文件：文件夹中的png文件
--------------------------------------------
打开文件夹：文件夹1
调用文本编辑器打开文件：文件夹1中的txt文件1
调用图片查看器打开文件：文件夹1中的png文件1
--------------------------------------------
--------------------------------------------
```

至此，我们已经使用组合模式将代码重写完毕，如果以后想要拓展一种文件类型，只需要创建一个类并继承`File`类就可以了

### 分析

#### 优点

组合模式为树结构的数据提供了一个完整的解决方案，让客户端可以统一的处理每个对象，而不需要考虑`叶子对象/组合对象`的区别

组合模式可以非常的进行维护和拓展

#### 缺点

组合模式由于对外暴露的统一接口，如果想对某种类型的文件做限制，对于客户端而言略显复杂

如果数据较多，遍历时间可能会比较长，可以考虑在父节点使用缓存方式来减少遍历时间
